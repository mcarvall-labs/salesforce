# AXF-137 — Horizon and scenario comparison engine

Engine slice of AXF-21 under `AXF-FORECASTING@1.0.0` (engine `forecast-horizon@1.0.0`).

## Components

| Component                                                                                          | Role                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ALT_CLS_ForecastComparisonService`                                                                | `compare(Input{accountIds, horizonMonths ∈ {3..24}, scenario, asOf})` → all eight horizons × three tiers per currency, month-by-month periods for the selected horizon, beyond-horizon obligations, overdue occurrences, sources, exclusions, reasons, confidence.                 |
| `AXF_CLS_CTRL_ForecastComparison` + `aXF_LWC_forecastComparison` + tab `AXF_CT_ForecastComparison` | UI: scope (dual listbox), horizon (8 buttons), scenario (3), confidence badge, explanation, beyond/overdue panels, all-horizons table, monthly table, sources; switching the scenario needs no server call (tiers already in the result); every update is announced (`aria-live`). |
| `AXF_CanCompareForecast`                                                                           | Capability in `AXF_PS_GestorFinanceiro`.                                                                                                                                                                                                                                           |

## Rules

- **Sources, counted once**: active `AXF_OBJ_FinancialSchedule__c` of authorized holders through `ALT_CLS_FinancialScheduleService.readProjection` (persisted + virtual occurrences, AXF-103 is the only projection engine) plus standalone `AXF_OBJ_FinancialTransaction__c` (no schedule, not cancelled, dated from asOf − 1 year). Persisted schedule occurrences carry `AXF_FTX_LKP_Schedule__c` and are therefore never read twice.
- **Tiers (v1, to ratify)**: schedule occurrence realized or with a contractual amount (fixed/calculated definition) → CONFIRMED; occurrence under an `ESTIMATED` definition → PROBABLE; standalone FTX `CONFIRMED` → CONFIRMED, `PLANNED` → PROBABLE, `PLANNED` + `IsEstimated` → UNCERTAIN. Confirmed FTX dated before asOf are history, not forecast.
- **Scenarios**: conservative = confirmed; intermediate = + probable; optimistic = + uncertain — integral amounts, no weighting (`conservativeNet == optimisticNet` whenever no probable/uncertain exists).
- **Beyond the horizon**: everything dated after the selected horizon (up to 24 months and beyond) is reported per horizon (`beyondOut/beyondIn/beyondCount`) and as reason `OBLIGATIONS_BEYOND_HORIZON`; a 24-month horizon still shows a 30-month plan as "beyond". Conservation: for every horizon, inside + beyond = the projection's `totalRemaining`.
- **Overdue**: occurrences before asOf are listed per currency (`OVERDUE_OBLIGATIONS`, DEGRADED) and never dropped.
- **Confidence**: BLOCKED when no authorized holder, when the scope exceeds `MAX_SCHEDULES` (12) / `MAX_PLANS` (2000) or when a projection is STALE/AMBIGUOUS/INVALID/UNSUPPORTED (a material commitment could be hidden); DEGRADED for partially shared holders (withheld, not summed), unbounded/incomplete coverage, overdue occurrences or incomplete contributions; otherwise INFORMATIVE. Results are display-only and never authorize a material action (`allowedActions` = review only).
- **Context**: `asOf` (echoed; `AS_OF_NOT_TODAY` when not today), `horizonEnd`, policy/engine version, currencies (`MULTI_CURRENCY`, no conversion), sources with projection revision, exclusions (`NOT_AUTHORIZED`, `NOT_A_HOLDER`, `COVERAGE_UNVERIFIED`).

## Validation

- AXON_DEV: `ALT_CLS_ForecastComparisonServiceTest` 5/5 (service 93 %, controller 86 %): 360-installment schedule with tracking start 5 and a 12-month persisted window under a 24-month horizon — 356 occurrences counted once, inside + beyond = remaining commitment for all eight horizons, monthly buckets equal the in-horizon count; tiers/scenarios integral; overdue visible; partial access withheld without leaking; stale projection BLOCKED; volume ceiling; asOf echo; guards; controller sanitization.
- Jest 2/2; ESLint clean.
